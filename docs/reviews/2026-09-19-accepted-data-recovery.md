incomplete observations from deleting receipt conflicts; and adds independent

or an accepted replacement; expiry controls projection, never receipt retention.

profiles/directory and verifies all active receipt profiles over HTTPS, regardless
of whether the latest publication mode is reviewed. The publisher runs this check
before committing, and the deployed verifier uses the previous Git parent as its
independent baseline.
