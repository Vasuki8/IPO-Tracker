# Recover the unaccepted diagnostic payloads

The [record archive](UNACCEPTED-candidate-records.json.gz) preserves the seven
complete changed records, their ordering, the immutable canonical base and the
expected hashes of both diagnostic datasets. It is 58,743 bytes and is explicitly
`UNACCEPTED`, with `publicationAllowed: false`. This is a lossless recovery
archive, not an accepted publisher transport.

The [recovery check](candidate-archive-recovery.json) recreated both full payloads
byte for byte from the archive and the committed base. Recovering those already
generated bytes requires no PDF download. Renewed extraction and source
acceptance still require the exact source documents and applicable review.

From this evidence directory, set `IPO_RECOVERY_REPO` to a clone containing base
commit `dd3a9b42057422057c98a16c9b1281cf318a54d8`, and set
`IPO_RECOVERY_OUT` to a new directory outside that clone. The following command
verifies the archive, base and both output hashes before saving either dataset:

```sh
uv run --frozen --project "$IPO_RECOVERY_REPO" python - <<'PY'
import copy
import gzip
import hashlib
import json
import os
from pathlib import Path
import subprocess

repo = Path(os.environ['IPO_RECOVERY_REPO']).resolve()
out = Path(os.environ['IPO_RECOVERY_OUT']).resolve()
assert not out.exists() and out != repo and repo not in out.parents
archive = Path('UNACCEPTED-candidate-records.json.gz').read_bytes()
assert hashlib.sha256(archive).hexdigest() == 'ed6e063ce087bea253d3b730e1facdf1fa4b199afe1eb9f0bb22575dfd629d03'
saved = json.loads(gzip.decompress(archive))
assert saved['status'] == 'UNACCEPTED' and saved['publicationAllowed'] is False
base_bytes = subprocess.check_output([
    'git', '-C', str(repo), 'show', saved['baseCommit'] + ':data/ipos.json'
])
assert hashlib.sha256(base_bytes).hexdigest() == saved['basePayloadSha256']
base = json.loads(base_bytes)
records = {row['id']: row for row in saved['records']}
verified = {}
for name, metadata in saved['outputs'].items():
    payload = copy.deepcopy(base)
    scope = set(metadata['changedIds'])
    payload['ipos'] = [records[row['id']] if row['id'] in scope else row
                       for row in payload['ipos']]
    body = (json.dumps(payload, indent=2, ensure_ascii=False) + '\n').encode()
    assert hashlib.sha256(body).hexdigest() == metadata['sha256']
    verified[name] = body
out.mkdir(parents=True)
for name, body in verified.items():
    (out / name).write_bytes(body)
    print(name, hashlib.sha256(body).hexdigest())
PY
```

The command leaves the clone unchanged and restores only diagnostic files. It
does not run the publisher, resolve Teamtech's conflicting units, accept the
seven-record scope, or complete P4. The Emmvee-only candidate still needs a
separately accepted publication path under the current source guard.
